# Lua Manipulation

A C++ project for working with and manipulating Lua in older Roblox clients.

Supports Roblox client versions ranging from **2007 to 2016**.

## Features

- Lua execution and runtime manipulation.
- Lua 5.1 integration.
- Legacy bytecode compilation.
- Runtime function discovery.
- Memory scanning and hooking.
- Native Lua function binding.
- Built-in script editor.
- Loading `.lua` and `.txt` files.
- Script output and error handling.

## Compatibility

Designed for 32-bit Roblox clients from 2007–2016.

Compatibility may vary depending on the client version and build.

## Building

### Requirements

- Windows
- Visual Studio
- MSVC v145 toolset
- Windows SDK
- Desktop development with C++

### Build instructions

1. Clone the repository.
2. Open `minecraft.sln` in Visual Studio.
3. Select `Release` configuration.
4. Select `Win32` platform.
5. Build the solution.

The compiled DLL will be located in the output directory.
